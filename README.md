# Must-Master DSA Problems

A curated, pattern-based list of the DSA problems worth knowing cold for interviews. Organized by topic in the order you should learn them — each topic builds intuition for the next. Based on the well-known Blind 75 / NeetCode 150 progression, trimmed and grouped for reference.

Check boxes off as you solve (and re-solve) them. Difficulty: 🟢 Easy · 🟡 Medium · 🔴 Hard

## How to use this

1. Go topic by topic, top to bottom — don't jump around.
2. Solve without looking at the solution first. If stuck > 25-30 min, read the approach, then re-implement from scratch.
3. Revisit a topic's problems a second time a week later. Recognition speed matters more than having solved it once.
